What is Web Development?

Web development = building websites with HTML (structure), CSS (style), and JavaScript (behavior). A “Buy” button: HTML puts it on the page, CSS makes it pink and round, and JavaScript adds the item to your cart.

What you'll learn

HTML

  • Tags: Labels in angle brackets that mark up content.
  • Links & images: <a> creates links; <img> shows images, with alt text for accessibility.
  • Semantic HTML: Tags that describe meaning, like <nav>, <header>, and <article>.

CSS

  • Selectors: Pick which elements a style applies to.
  • Box model: Every element is a box: content, padding, border, margin.
  • Flexbox & Grid: Layout systems for lining things up in rows, columns, or grids.

JavaScript

  • DOM: The browser's live model of the page, which JavaScript can read and change.
  • Events: Things that happen, like clicks or typing, that code can react to.
  • fetch: Loads data from a server without reloading the page.

Responsive & shipping

  • Responsive design: Layouts that adapt to any screen size.
  • Git: Version control that tracks every change and helps teams collaborate.
  • Deploy: Publishing your site to a host so others can visit it.
