What is Excel & Spreadsheets?

Excel is a spreadsheet: a grid of cells where you store data and use formulas to calculate, sort, and summarize it. Type =SUM(B2:B13) and Excel adds up a whole year of monthly expenses instantly.

What you'll learn

Formulas & functions

  • SUM: Adds up a range of numbers.
  • AVERAGE: Finds the mean of a range.
  • IF: Returns one value if a condition is true, another if false.

References & lookups

  • Relative reference: A1-style refs shift when you copy the formula.
  • Absolute reference: $A$1 stays locked when copied.
  • XLOOKUP: Finds a value in one column and returns the matching value from another.

Pivot tables

  • Pivot table: Groups and summarizes data by category, no formulas needed.
  • Rows & Values: Drag a field into Rows to group by it, and into Values to sum or count it.
  • Filters: Show only part of the data in the pivot.

Charts & clean sheets

  • Line chart: Shows trends over time.
  • Conditional formatting: Colors cells automatically based on rules.
  • Freeze panes: Keeps headers visible while you scroll.
