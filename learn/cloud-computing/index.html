What is Cloud Computing?

Cloud computing = renting computing power, storage, and services over the internet instead of owning servers. A streaming service rents extra servers for Friday-night peaks and gives them back on Monday morning.

What you'll learn

Service models

  • IaaS: Infrastructure as a Service: rent virtual servers, storage, and networks.
  • PaaS: Platform as a Service: upload your code; the provider runs the servers.
  • SaaS: Software as a Service: ready-to-use apps in the browser.

Core services

  • Compute: Virtual machines or containers that run your code.
  • Object storage: Cheap, durable storage for files of any kind.
  • Serverless: Code that runs only when triggered; no servers to manage, pay per run.

Scaling & reliability

  • Auto scaling: Automatically adds or removes servers based on demand.
  • Load balancer: Spreads incoming traffic across multiple servers.
  • Availability zones: Separate data centers in one region, so a single failure doesn't take you down.

Cost & security

  • Shared responsibility: The provider secures the infrastructure; you secure your data, users, and settings.
  • IAM: Identity and access management: who can do what. Give the least access needed.
  • Cost controls: Budgets, alerts, and shutting down unused resources.
