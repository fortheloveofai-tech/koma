What is Data Analysis?

Data analysis = collecting, cleaning, and exploring data to answer questions and guide decisions. A café notices sales drop 30% on rainy days, so it launches a rainy-day delivery deal.

What you'll learn

Data cleaning

  • Duplicates: The same record appearing more than once, which inflates totals.
  • Missing values: Blank cells that need a decision: remove, fill, or flag.
  • Consistency: The same thing written the same way across the data.

Descriptive statistics

  • Mean: The average: add everything up, then divide by the count.
  • Median: The middle value when sorted. Extreme values don't pull it around.
  • Outlier: A value far from the rest that can distort averages.

Visualization

  • Line chart: Shows change over time.
  • Bar chart: Compares amounts across categories.
  • Scatter plot: Shows the relationship between two numbers.

Correlation & storytelling

  • Correlation: Two things moving together. It does NOT prove one causes the other.
  • A/B test: Compare two versions with random groups to see what actually causes a change.
  • Insight → action: A good finding ends with a clear recommendation.
