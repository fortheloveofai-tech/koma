What is Python Programming?

Python is a programming language that reads almost like English. It's used for automation, data, web apps, and AI. A 5-line Python script can rename 1,000 photos in a folder in under a second.

What you'll learn

Variables & types

  • Variable: A name that points to a value. Create one with =.
  • String: Text inside quotes. You can join strings with +.
  • List: An ordered collection in square brackets. Counting starts at 0.

Decisions & loops

  • if / else: Run code only when a condition is True; otherwise run something else.
  • for loop: Repeat code once for each item in a sequence.
  • Comparisons: == equal, != not equal, > and < compare sizes. They give True or False.

Functions

  • def: Defines a function: a named, reusable block of code.
  • Parameters: Inputs a function accepts, listed in its parentheses.
  • return: Sends a value back to whoever called the function.

Libraries & projects

  • import: Loads a library so you can use its tools.
  • pip: Python's installer for third-party packages.
  • Popular libraries: pandas for data tables, requests for web calls, matplotlib for charts.
