What is SQL & Databases?

SQL (Structured Query Language) is how you ask databases questions: find, filter, combine, and summarize data. SELECT name FROM customers WHERE city = 'Austin'; lists every customer in Austin.

What you'll learn

SELECT & WHERE

  • SELECT: Chooses columns to show. SELECT * means all columns.
  • WHERE: Keeps only rows that meet a condition.
  • ORDER BY / LIMIT: Sorts results and caps how many come back.

Aggregates & GROUP BY

  • COUNT: Counts rows.
  • GROUP BY: Splits rows into groups so aggregates run per group.
  • HAVING: Filters groups after aggregating (WHERE filters rows before).

JOINs

  • Primary & foreign key: A primary key uniquely identifies a row; a foreign key points to it from another table.
  • INNER JOIN: Returns only rows that match in both tables.
  • LEFT JOIN: Returns every row from the left table, plus matches from the right (blank if none).

Changing data safely

  • INSERT: Adds new rows.
  • UPDATE: Changes existing rows. Always use WHERE!
  • DELETE: Removes rows. Without WHERE, it removes all of them.
